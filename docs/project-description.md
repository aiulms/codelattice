## 项目介绍

CodeLattice 是面向开发者与 AI 编程助手的本地代码图谱引擎，用于理解项目结构、追踪调用与依赖、评估变更影响和辅助提交前审查。

支持 Rust、仓颉、ArkTS、TypeScript、JavaScript、C/C++、Python 和 Shell，提供 CLI、MCP 与可视化工作台，适合接手陌生项目、维护大型遗留代码和规划重构。

分析引擎本地运行，不执行目标项目脚本；结果保留源码位置、置信度和诊断依据。当前为 Beta，桌面工作台为 P0 开发构建，静态结论需结合编译、测试和运行验证。模型解释可选；远程模型会接收结构化图证据，默认不发送源码正文。
